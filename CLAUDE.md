# Ohana Property & Transition Services: working rules

## Reference assets (load before any visual generation)
- `brand/ohana-badge.png`: the official badge. Never improvise or recolour a logo.
- `brand/fleet/*.jpg`: the real vehicles: white Ram 2500 Sport, yellow Sure-Trac tandem dump trailer, red Ford Ranger XLT.
- Rented trucks never carry the Ohana logo.
- `brand/README.md` has the details.

## People on screen
- Real crew footage is captioned as the Ohana crew.
- Marco Rojas (AI persona modeled on co-owner Hansel Ortega) and Hansel's Captions AI clone are generated people:
  generated scenes only, always with the platform's AI label. Marco's spec lives in `continuity/marco-rojas/BRIEF.md`.

## Assets
- Generated images and videos are committed to this repo in the same session they're made.
  If the image server is blocked, stop and flag it before generating, not after (preflight in BRIEF §9).
- Blur plates, temp tags, house numbers, written names and the faces of minors before anything is committed or posted.

## Reels
- Build with `social/reelkit/render.py` and a per-reel `spec.json`; follow `social/reelkit/Reel-Style-Rules.md`
  (Instagram safe area: text and phone number inside y 220–1540, x ≤ 940; -14 LUFS; ship `cover.jpg`).
- Service claims: junk removal, clean-outs, hauling, property transitions only.

## Text for the owner to paste
- Write it ready to use, with no placeholders. If a value is unknown, ask for it directly instead.
